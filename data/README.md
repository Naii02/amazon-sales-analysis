# Data

The dataset used in this project is **not included** in this repository due to file size.

## How to get it

1. Go to [Amazon Sales Dataset on Kaggle](https://www.kaggle.com/datasets/aliiihussain/amazon-sales-dataset)
2. Download the CSV file
3. Place it in this `/data` folder and name it `amazon_sales.csv`

The notebook expects the file at: `data/amazon_sales.csv`
